# 初心者向けUIデバッグ環境仕様

## 目的・構成
- Pythonテンプレートに、初心者が画面を確認しながらUIをデバッグできる最小環境を追加する。
- 構成はVite + React + TypeScriptとする。
- 仕様作成後、ユーザーの明示的な実装指示を受けて実装する。委任された詳細は以下の「実装時の決定事項」に記録する。

## 入出力・動作
- 画面にサンプル画像と複数のラベルを表示する。
- 入力はユーザーによるラベル選択とし、同時に選べるラベルは1つだけとする。
- 選択したラベルと選択処理を画面で確認できるようにする。
- VS CodeからF5等で画面を起動し、ブラウザーで表示しながらReact/TypeScriptコードのブレークポイントデバッグができるようにする。

## 制約・文書化
- データ/API/backendには接続せず、永続保存もしない。Python側との連携は対象外とする。
- 既存のPython 3.12 + uv環境とPython向け設定を維持する。Pythonのクラスやディレクトリの責務変更は本仕様に含めない。
- 実装時にREADMEへ、初回利用者向けのNode.jsの前提、最小限の導入・起動・操作手順、F5デバッグ方法を記載する。
- サンプルUIの仕様と操作、およびAPI/backend未接続であることを文書に明記する。

## 受け入れ条件

- `docs/` 以下に合意事項を記録し、コードは変更しない。
- 実装や次のエージェント呼び出しを行わない。

### 後続の実装工程で満たす条件

- サンプルUIの仕様と操作が記録されている。

## 実装時の決定事項
- 配置先は `frontend/`。Pythonの設定・依存・ロックファイルを変更せず、npmで独立管理する。
- Node.jsは24 LTS（24.x）、同梱のnpmを使用する。Windows PowerShellでは実行ポリシー変更を避けるため `npm.cmd` を使用する。
- レジストリで互換条件を確認したVite 8.3.5、React/React DOM 19.3.1、TypeScript 7.0.2、Reactプラグイン6.2.1を使用する。React型定義は19.3.0。直接依存は固定し、間接依存は `package-lock.json` で固定する。
- 画像は同梱の自作SVGによる猫のイラスト。外部画像・フォント・APIを取得しない。
- ラベルは「猫」「犬」「鳥」の3つ。ラジオボタンで単一選択し、初期状態は未選択。正誤判定なし。
- 「選択中のラベル」と「直前の選択処理（変更前 → 変更後）」を表示する。初期の処理表示は「まだ選択していません」。再読み込みで初期化する。同じ選択済みラベルでは変更処理は発生しない。
- 選択処理は `frontend/src/App.tsx` の `handleLabelChange`。変更前・変更後の値をブレークポイントで確認できる。
- 開発サーバーは `127.0.0.1:5173` 固定、使用中ならエラーにして別ポートへ自動変更しない。
- VS Codeはリポジトリルートを開く。先に `frontend` 内で `npm.cmd ci`、`npm.cmd run dev` を実行し、F5でMicrosoft Edgeを起動する。開発サーバー起動は手動で、F5はブラウザー起動のみ。追加拡張は不要。
- VS Codeの既存Python設定・推奨拡張は維持し、ブラウザー用の `launch.json` のみ追加する。
- 最小自動検証は `npm.cmd run build`（TypeScript型チェックとViteビルド）。画面操作・F5停止はユーザーによる手動確認対象。
